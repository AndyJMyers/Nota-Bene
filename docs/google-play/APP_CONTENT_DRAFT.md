# Nota Bene — App content and review draft

Use the final build, not this note alone, when answering Play Console.

## Product position

Nota Bene is a local-first productivity organiser made of user-created TODO, LOG, RECORD and REPEAT collections. It does not provide category-specific advice, interpretation or external services.

## Proposed declarations

| Console section | Proposed answer for the present build |
| --- | --- |
| App access | All functionality is available without a login. No reviewer instructions needed. |
| Ads | No ads. |
| Target audience | Adults; do not include children. |
| Content rating | Complete the questionnaire truthfully from the final build; it should contain no violence, sexual content, gambling, news or user-to-user social features. |
| Permissions | Notifications are optional and requested only when a user enables a repeat reminder. Boot reception restores those optional reminders. No SMS, call log, contacts, location or storage permission is used. |
| Government / financial / clinical declarations | Not applicable to the intended generic build. Do not select special-purpose categories. |

## Reviewer note, if a free-text field is offered

`Nota Bene is an offline-first productivity organiser. Reviewers can create, rename and remove local collections without an account. Optional speech and image-text capture are system / on-device input methods; accepted text remains editable before storage.`

## Final check

Re-read the selected declarations after uploading the release bundle. The manifest, permissions, SDK inventory, in-app copy, store listing and screenshots must all describe the same generic product.
