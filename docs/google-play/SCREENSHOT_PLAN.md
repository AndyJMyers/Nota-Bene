# Nota Bene — screenshots pending final tab refinement

Do not capture or upload screenshots until the tab naming, order and example records have been settled on the phone.

## Capture set

1. **TODO** — a short, readable list showing a completed item and an open one.
2. **LOG** — a named collection with a few dated entries.
3. **RECORD** — a named collection with a compact record and reference value.
4. **REPEAT** — a named item showing its interval, optional reminder, `LOG` button and visible event history.
5. **Personalisation** — one selected visual treatment with the `MOOD >` control and background plainly visible.
6. **Settings** — XLSX import/export, local-data explanation and installed build number.

## Rules

- Capture on the intended phone at native resolution, portrait unless the final presentation calls for a landscape image.
- Use invented, generic example records. Do not imply a regulated-purpose app.
- Do not show private records, notification content, system keyboard, permission prompts or file-picker locations.
- Show the generic collection names and the actual UI; never annotate screenshots with claims the app cannot demonstrate.
- Keep a source copy of every chosen screenshot in this folder before uploading to Play.
