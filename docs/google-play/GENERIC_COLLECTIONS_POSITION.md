# Nota Bene — generic collections position

Nota Bene is a local-first productivity organiser. It begins with TODO and lets the user create named TODO, LOG, RECORD and REPEAT collections.

The app does not offer banking, transfers, loans, wallets, financial advice, clinical functions, diagnosis, treatment, reminders tied to a regulated category, or integrations with external services. A user decides the meaning of their own private collection and text.

All records remain in the on-device database unless the user explicitly exports an XLSX workbook. Android cloud backup and device-transfer backup are disabled. Speech and image-text capture are optional input methods; the accepted text is editable before storage.
